1. Descarga el archivo

Se llama

2. Enlace para el código QR

Cuando compres tu dominio, cambia la dirección aquí. Genera los QR recién con el dominio definitivo: el código grabado no se puede cambiar.

3. Súbelo a tu proyecto

  1. Guarda el archivo en public/data/memoriales/
  2. Crea la carpeta y pon ahí las fotos, con los mismos nombres que escribiste.
  3. Haz commit y push a GitHub. Cloudflare publica los cambios solo.
  4. Abre el enlace en tu celular y confirma que se ve bien antes de hacer el QR.

Vista previa en celular

Es la dirección que te da Live Server (normalmente http://127.0.0.1:5500) o Wrangler (http://localhost:8787). Tiene que estar corriendo para ver la vista previa.

Las fotos se ven cuando ya copiaste los archivos a la carpeta del memorial en public/images/memoriales/.
